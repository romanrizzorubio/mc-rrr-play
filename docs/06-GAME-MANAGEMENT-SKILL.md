# Skill de Gestión de Partida: Marvel Champions

Este documento sirve como una guía rápida y exhaustiva para gestionar una partida de Marvel Champions, sintetizando las reglas fundamentales y los procedimientos paso a paso. Utiliza esta guía para asegurar que todas las fases y activaciones se resuelvan correctamente.

---

## 1. Preparación de la Partida (Setup)

Para una preparación detallada, consulta el [Apéndice II](02-10-APPENDIX-II-SETUP.md). Pasos clave:

1.  **Héroes**: Seleccionar superhéroes, establecer puntos de vida (identidad de alter ego inicial) y apartar obligaciones y conjuntos de archienemigo.
2.  **Villano**: Seleccionar escenario, establecer puntos de vida del villano y crear el mazo de encuentros (incluyendo obligaciones).
3.  **Mazo de Jugador**: Barajar y robar hasta el tamaño de mano. Se permite un **Mulligan** (descartar y robar de nuevo).
4.  **Reserva**: Preparar fichas de daño, amenaza, aceleración y cartas de estado (**aturdido**, **confundido**, **duro**).
5.  **Comienzo**: Resolver capacidades de "Preparación" y pasar a la Fase de Jugador.

---

## 2. Estructura de la Ronda

Cada ronda consta de dos fases principales:

### A. Fase de Jugador
En orden de jugador, cada jugador toma su turno.
*   **Opciones en el turno**:
    *   **Cambiar de identidad**: De héroe a alter ego o viceversa (1 vez por turno).
    *   **Jugar cartas**: Pagar el coste en recursos para jugar aliados, mejoras, apoyos o eventos.
    *   **Atributo básico**: Usar **ATQ** (ataque), **INT** (intervención) o **REC** (recuperación) agotando la identidad.
    *   **Acciones**: Activar capacidades de "**Acción**" en cartas en juego o eventos en mano.
    *   **Aliados**: Agotar aliados para atacar o intervenir (sufriendo **daño derivado**).
*   **Fin de la fase**:
    1.  Descartar cartas sobrantes (opcional).
    2.  Robar hasta el tamaño de mano.
    3.  **Preparar** todas las cartas agotadas.

### B. Fase del Villano
1.  **Colocar amenaza**: Añadir amenaza al plan principal según el valor de aceleración (+ iconos/fichas).
2.  **Activación de Enemigos**: Por cada jugador (en orden):
    *   **Villano se activa**:
        *   Si el jugador está en **héroe**: El villano **ataca**.
        *   Si el jugador está en **alter ego**: El villano **ejecuta el plan**.
    *   **Esbirros se activan**: Cada esbirro enfrentado al jugador ataca o ejecuta el plan según la identidad del jugador. Si varios deben activarse, elige el siguiente en diálogos sucesivos; el último se activa sin diálogo.
3.  **Repartir cartas de encuentro**: Una a cada jugador (+ iconos de riesgo).
4.  **Mostrar cartas de encuentro**: En orden, cada jugador muestra y resuelve su(s) carta(s).
5.  **Pasar el marcador**: El marcador de jugador inicial pasa a la izquierda.

---

## 3. Gestión de Combate y Activaciones

### El Ataque del Villano
1.  **Declarar defensor**: El jugador puede defender con su héroe (agotándolo), con un aliado o pedir a otro jugador que defienda.
2.  **Carta de aumento**: Dar una carta de aumento boca abajo al villano.
3.  **Resolver aumento**: Mostrar la carta y sumar sus iconos de aumento al **ATQ** del villano. Resolver efectos de estrella (**Aumento**).
4.  **Calcular daño**: (ATQ Villano + Aumento) - DEF (si el héroe defendió).
5.  **Aplicar daño**: Colocar fichas de daño en el objetivo. Si no hubo defensor, el ataque es **no defendido** y el daño va al héroe.

### Ejecución del Plan
1.  **Carta de aumento**: Dar una carta de aumento al villano.
2.  **Resolver aumento**: Sumar iconos al valor de **PLA** (planificación).
3.  **Colocar amenaza**: Añadir amenaza al plan principal igual al valor total.

## 4. Estados y Palabras Clave Críticas

*   **Aturdido**: La siguiente vez que el personaje fuera a atacar, descarta esta carta en vez de eso.
*   **Confundido**: La siguiente vez que el personaje fuera a intervenir o ejecutar el plan, descarta esta carta en vez de eso.
*   **Duro**: Evita la siguiente vez que el personaje fuera a sufrir daño. Descarta esta carta.
*   **Oleada**: Tras mostrar esta carta, muestra otra carta de encuentro.
*   **Brutalidad**: El daño sobrante tras derrotar a un aliado/esbirro se inflige al héroe/villano.
*   **Peligro**: No se puede consultar con otros jugadores mientras se resuelve esta carta.

---

## 5. Glosario Rápido (Consistencia Terminológica)

| Término | Acción / Definición |
| :--- | :--- |
| **Agotar** | Girar la carta 90º para usar una capacidad o atributo. |
| **Preparar** | Poner la carta en posición vertical (listo para usar). |
| **Intervenir (INT)** | Quitar amenaza de un plan. |
| **Plan secundario** | Plan adicional que añade efectos negativos o iconos de aceleración/riesgo. |
| **Perfidia** | Carta de encuentro con efectos de un solo uso (se descarta tras resolverse). |
| **Vincular a** | Instrucción para colocar un accesorio sobre otra carta. |

---
**Consejo de Gestión**: Mantén siempre el mazo de encuentros y la pila de descartes accesibles. Si el mazo de encuentros se agota, añade una ficha de aceleración al plan principal y baraja los descartes para crear un nuevo mazo.
